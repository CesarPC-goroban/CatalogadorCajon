# 📦 Catalogador de Cajón

Un proyecto desarrollado en **Java** utilizando **Maven** para la gestión estructurada y ordenación de objetos cotidianos. Este desarrollo ha sido creado con el objetivo de reactivar, consolidar y actualizar mis conocimientos en Programación Orientada a Objetos (POO).

## 🚀 Características
- **Estructura POO limpia:** Separación de lógica en clases independientes (`Main` y `ObjetoCajon`).
- **Colecciones dinámicas:** Uso de `ArrayList` para gestionar elementos en memoria.
- **Formateo personalizado:** Sobrescritura del método `@Override toString()` para una visualización limpia y organizada de los datos en consola.
- **Gestión moderna:** Configurado bajo el entorno profesional de **IntelliJ IDEA** utilizando el sistema de construcción **Maven**.

## 🛠️ Tecnologías utilizadas
- **Lenguaje:** Java 27 (OpenJDK)
- **Gestor de proyectos:** Maven
- **IDE:** IntelliJ IDEA
